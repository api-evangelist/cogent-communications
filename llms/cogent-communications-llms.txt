# Cogent Communications

> Cogent Communications Holdings, Inc. (NASDAQ: CCOI, AS174) is a Tier 1 facilities-based
> internet service provider selling Dedicated Internet Access, IP Transit, Ethernet, MPLS
> IP-VPN, SD-WAN, optical wavelength transport and colocation over its own global fibre
> network. **Cogent publishes no public API, no developer portal and no machine-readable
> contract.** This file is generated by API Evangelist from a public profile of Cogent's
> website; it is not published by Cogent.

## Customer portals (login required, not APIs)

- [eCogent](https://ecogent.cogentco.com/): Cogent's customer portal — billing, orders, support tickets,
  DNS change requests, IP and BGP request forms, contact management. Available to current Cogent
  customers only; no programmatic interface is documented.
- [Global Peer Exchange](https://globalpeerexchange.com/): portal for Global Peer Connect ports and
  peering with other GPE participants. Registration/login required.
